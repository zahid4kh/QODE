# Moving and renaming files (refactor)

## moving files in the explorer

`explorer/ExplorerTree` (the explorer's `QTreeView`) is a drag source *and* target: `startDrag` builds a chip pixmap + URL/`application/x-qode-explorer-paths` mime, `dragMoveEvent` computes a `Verdict` (`verdictAt`: Ok / SameFolder / IntoItself / NameTaken) for the folder under the cursor (a file means its parent), opens collapsed folders after 650 ms, auto-scrolls near the edges, and `paintEvent` draws the highlighted folder block plus an in-viewport hint pill (no tooltip window, so it works on Wayland too; `previewDrag` fakes it for screenshots/tests). A drop only emits `moveRequested`; `refactor/MoveController` (owned by `MainWindow`) does the work: it plans on a worker thread (`ProjectFiles::scan` + `MoveRefactor::plan`, open editors' text as overrides), renames on disk, announces each move through `ProjectExplorer::notifyMoved` (→ `pathRenamed`, so tabs/preview follow), applies the edits (open documents through `CodeEditor::applyOffsetEdits` + `EditorManager::saveQuietly` when they were clean, closed files rewritten on disk after a hash check) and shows a `ProjectExplorer::Notice` bar with Undo (inverse edits + moves back) and Details. `src/refactor/MoveRefactor` is pure Qt Core (no GUI, thread safe, usable from tests): `plan(Input)` returns per-file `TextEdit` lists (offsets into the text it was given) for the new location of each file. `Ctx` holds the moves (`map`/`unmap`), cached stat/text, emitters (overlapping edits are dropped); the passes are `RefactorWeb.cpp` (JS/TS incl. tsconfig/jsconfig `paths`/`baseUrl`/`extends`/`references`, CSS/SCSS partials, HTML/Vue/Svelte attributes and root-relative `/x` URLs, Markdown, JSON/tsconfig/components.json/package.json scripts, PHP, shell, Dart, Ruby), `RefactorPython.cpp` (relative + dotted imports, `from pkg import a, b` split when names land in different modules, `import a.b.c` usages, "pkg.mod" strings, config files), `RefactorJvm.cpp` (package statement from the new folder under the file's source root, imports/wildcards/static/aliases, same-package users get explicit imports, redundant ones removed, FQNs in strings/XML/gradle, package renames), `RefactorNative.cpp` (`#include` resolution against include roots, CMake/qmake/Make/Meson/Cargo/qrc/ui path tokens, QML imports + implicit sibling types, Go import paths + package clause) and `RefactorRust.cpp` (module tree: `mod` declarations move between parents, `use` trees and `crate::/self::/super::` paths). To support another language add a pass there and call it from `plan()`; every pass edits the text of the file as it is before the move (`Ctx::emitter` is keyed by the old path).

## Linux and Windows

- Windows cannot rename or move a folder while anything below it is watched. Every rename or move holds a `WatchGuard::Scope`, which pauses all registered watchers (`WatchGuard::registerWatcher` / `registerOwner`). A new long-lived `QFileSystemWatcher` must register.
- Compare paths with `Platform::samePath` / `isUnder` (case-insensitive on Windows), never `==` or `startsWith(root + '/')`.
